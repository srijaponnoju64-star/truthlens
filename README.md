# TruthLens - AI Multimodal Fake News Detector 
TruthLens is an AI-powered web application that detects fake news and misinformation across multiple modalities including Text, Images, and Audio using Groq LLM. 
 
## Modules 
- Module 1: Text fake news detection 
- Module 2: Image manipulation detection 
- Module 3: Social media post analysis (Image + Text) 
- Module 4: Full multimodal analysis (Image + Text + Audio) 
 
 
## Tech Stack 
## Tech Stack 
- FastAPI, Python, Groq LLM, Jinja2, SQLite
